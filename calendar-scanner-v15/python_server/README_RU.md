# «Нарисуй сам» — Python-сервер

Сервер работает на стандартной библиотеке Python 3.11+ и не требует Replit или другого внешнего конструктора.

## Что уже реализовано

- раздача текущего интерфейса V15;
- проверка состояния сервера;
- выдача юридических документов из одного источника;
- отдельный журнал принятия каждого согласия;
- хранение проектов в SQLite;
- хранение исходной и обработанной версии каждой из 13 страниц;
- обращения в поддержку с проектом, страницей, этапом и техническим контекстом;
- конфигурация будущих входов через почту, Telegram, MAX и VK;
- вход по одноразовому шестизначному коду на почту, с ограничением попыток и серверной сессией;
- отдельные конфигурационные адаптеры для Telegram, MAX и VK;
- ограничения размера запросов и изображений;
- безопасная раздача статических файлов и базовые HTTP-заголовки защиты.

## Локальный запуск

```bash
cd python_server
python3 run.py
```

Приложение откроется по адресу `http://127.0.0.1:8080`.

## Production

Перед запуском заполнить переменные из `.env.example`. Особенно важны реквизиты ИП и каталог данных. Для Linux-сервера можно запустить:

```bash
gunicorn --workers 3 --bind 127.0.0.1:8080 wsgi:application
```

Перед приложением ставится HTTPS-прокси. Каталог `DATA_DIR` должен регулярно резервироваться. Первичное хранение персональных данных граждан России должно находиться на территории России.

## Что подключается после получения доступов

- SMTP-доставка одноразового кода по почте;
- перенаправления и проверка ответов Telegram, MAX и VK;
- российское объектное хранилище для фотографий и PDF;
- платёжный провайдер и онлайн-касса ИП;
- API типографии;
- реальная доставка обращений в поддержку.
